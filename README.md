# 🌍 Jajabor AI

### AI-Powered Travel Planning Agent

*Wander Freely. Plan Intelligently.*

Jajabor AI is an intelligent travel planning assistant built using LangChain, LangGraph and Generative AI. The project aims to leverage Agentic AI to simplify end-to-end travel planning by providing personalized flight, train and hotel recommendations, along with day-wise travel itineraries based on user preferences.
